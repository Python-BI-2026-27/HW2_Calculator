# Team 1 W2 Calculator

Простой калькулятор на Python, реализующий базовые математические операции.
Каждая функция была написана отдельным участником команды.

## Функционал

- Сложение двух чисел
- Вычитание двух чисел
- Умножение двух чисел
- Деление двух чисел (с обработкой деления на ноль)

## Как запустить

python calculator.py

## Состав команды

- Кудайбергенов — тимлид, функция main
- Оцелюк — функция вычитания
- Никитин — функция умножения
- Акименкова — функция деления
- Салова — функция сложения
