## **Calculator**



Here is our simple and fast calculator written in **Python**, which can perform four basic arithmetic operations: addition, subtraction, multiplication, and division.

The program accepts an arithmetic expression (two numbers and an operator separated by spaces), carries out calculation and prints the result.



### ⭐ **Usage and functions**

You can enter your expression like this:
`x op y`

**Parameters:**

`x` - the first number

`op` - arithmetic operation you would like to perform

`y` - the second number

**Supported operations:**

   | op   | operation      |
   | ---- |:-------------: |
   | +    | addition       |
   | *    | multiplication |
   | -    | subtraction    |
   | /    | division       |




**Functions** used in this program:



`main(x, op, y)` — receives your arithmetic expression and transfers it to the next function depending on the chosen operation


`addition(x, y)` — adds numbers together

`multiplication(x, y)` — multiplies number x by number y

`subtraction(x, y)` — calculates the difference between x and y

`division(x, y)` — calculates the quotient of x and y


♦️ **Division by zero**

The calculator prevents division by zero and displays an error message.
