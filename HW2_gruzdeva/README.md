# HW2: Calculator

Мини-программа `calculator.py`. Программа принимает на вход (через `input()`) строку с некоторым математическим выражением и печатает число - результат вычисления этого выражения.

---

## Поддерживаемые функции

Калькулятор поддерживает следующие арифметические операции:
1.  **`add` (`+`)** — вычисление суммы двух чисел.
2.  **`subtraction` (`-`)** — вычисление разности двух чисел.
3.  **`multiply` (`*`)** — нахождение произведения двух чисел.
4.  **`divide` (`/`)** — частное двух чисел.

---

## Правила использования программы

При запуске соблюдайте следующие правила:

1.  **Запуск:** Запустите главный файл программы через терминал:
    ```bash
    python main.py
    ```
2.  **Ввод чисел:** Введите первое число, операцию, а затем второе. Все указанные элементы разделяйте пробелами. На ноль делить **ЗАПРЕЩЕНО!**
