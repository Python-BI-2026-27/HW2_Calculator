# HW2:Calculator

Скрипт калькулятора для вычисления простых арифметических выражений из двух чисел и оператора (`+`, `-`, `*`, `/`).
Принимает на ввод строку из двух чисел и математичского оператора между ними. Разделитель между всеми элементами пробел.
Выводит результат математической операции.

## Команда №5
* **Прокопенко** (Тимлид) — форк репозитория, функция `main`, README.md, финальный merge.
* **Выноградская** — функция вычитания`subtract`.
* **Данилова** — функция умножения `multiply`.
* **Киренская** — функция деления `divide`.
* **Эпик** — функция сложения`add`.
