# HW2: Calculator

Программа `calculator.py` предназначена для выполнения простых вычислений (сложение,умножение,деление, вычитание).На вход принимает строку с математическим выражением и выводит число - результат вычисления этого выражения.

Для корректной работы программы необходимо чтобы выражение состояло из двух чисел (`int` или `float`) и математического оператора между ними (один из 4: `+ - * /`). Все указанные элементы разделены пробелами (пример: `5 - 3`). 

**Пример работы:**

```
Введите выражение: 5 - 3
2.0
```
