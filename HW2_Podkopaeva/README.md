# Описание
Программа calculator.py представляет собой калькулятор, в котором доступны 4 операции:
- сложение (+)
- вычитание (-)
- умножение (*)
- деление (/)

## Входные данные
Программа на вход ожидает строку формата **'x op y'**, где

- x - первое число
- op - операция (+, -, *, /)
- y - второе число

числа могут иметь формат int, float

## Выходные данные

Программа выдаёт одно число - результат операции

Если введённая операция некорректна, то программа выводит сообщение "Некорректное выражение" 

Если выбрана операция деления и y = 0, программа выводит сообщение "Деление на 0"

# Вызов
`python HW2_Podkopaeva/calculator.py`
