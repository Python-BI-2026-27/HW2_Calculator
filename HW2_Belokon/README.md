# HW2: Calculator

Данная программа принимает на вход строку с некоторым арифметическим выражением от пользователя и выводит на экран результат этого выражения типа float. 

# Структура программы

В программе реализованы 5 функций:
- main принимает строку от пользователя с выражением, режет ее на три части, переводит a и b в тип float и передает ее другим функциям на вычисление в зависимости от оператора, а затем выводит результат выражения на экран;
- add складывает a и b, заданные пользователем;
- subtract вычитает b из a;
- multiply перемножает a и b;
- divide делит a на b.
